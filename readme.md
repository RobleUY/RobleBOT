## 📖 Presentación

**RobleBOT** es un bot de WhatsApp pensado para facilitar la administración de grupos, ofrecer entretenimiento y automatizar tareas con IA, descargas, juegos y funciones sociales.

Esta publicación deja visible únicamente lo esencial del proyecto: el archivo ZIP y su documentación pública.
